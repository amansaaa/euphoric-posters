# Euphoric Posters

I used to run Euphoric Posters, a poster brand where I designed and sold posters through Shopify, with printing and shipping handled by global external providers. Shopify abstracted the entire backend, hence this project rebuilds the store from scratch to remove the dependency (and the $50/month subscription ). Built as if real customers will use it, however, the checkout will be turned off though.
